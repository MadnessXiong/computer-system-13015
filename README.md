# 13015 计算机系统原理学习资料

这是可直接用于 GitHub Pages 的静态网页。`index.html` 是章节学习页，`practice.html` 是答题页；其他文件是题库、复习资料和离线压缩包。网页无需服务器程序或数据库。

## 发布到 GitHub Pages

1. 在 GitHub 新建 **Public** 仓库，例如 `13015-study`。
2. 将本文件夹内的文件上传到仓库根目录。上传文件时选择本文件夹里的各个文件；不要只上传 ZIP，因为 GitHub Pages 不会自动解压它。
3. 打开仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
4. 等待 GitHub Pages 发布，访问 `https://<你的GitHub用户名>.github.io/<仓库名>/`。答题页地址是同一网址后加 `practice.html`。

GitHub Pages 站点公开可见；题目及解析中的 A/C/D 来源分类、适用限制应保留。答题进度只保存在当前浏览器，换设备前请在答题页点击“导出进度”，在另一台设备点击“导入备份”。

原始资料和来源说明见 `使用说明与来源.md`；完整离线包是 `13015_按教材章节学习方案_20261018.zip`。
