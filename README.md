## 建议怎样用

1. 从[章节学习页](https://madnessxiong.github.io/computer-system-13015/)读一节，尝试不看答案复述原理并手算例题。
2. 到[答题页](https://madnessxiong.github.io/computer-system-13015/practice.html)选择同一章节或知识点练习，先独立作答，再看解析和常见错误。
3. 完成一章后做大题训练，按“条件 → 原理或公式 → 步骤 → 结果与单位”写出完整过程；回到错题本复练。

答题记录只保存在**当前浏览器**，不同设备之间不会自动同步。换设备前在答题页点击“导出进度”，新设备上点击“导入备份”。网页和离线包均不需要注册账号才能阅读或答题。

资料内容核对至 **2026 年 10 月 18 日**。后续新增真题或教材要求时，应重新核验来源和适用性，再更新题库。
